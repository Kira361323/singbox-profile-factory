# Источники

Формат:

```text
имя пробел URL
```

Поддерживаются:

- raw-ссылки;
- GitHub blob-ссылки, они автоматически превращаются в raw;
- текстовые списки `vmess://`, `vless://`, `trojan://`, `ss://`, `ssr://`;
- обычные subscription URL, если их умеет парсить subconverter.

Примеры:

matin https://raw.githubusercontent.com/MatinGhanbari/v2ray-configs/main/subscriptions/v2ray/all_sub.txt
aetris https://github.com/flaafix/AetrisVPN/blob/main/AetrisVPN.txt
